# ИЭТР «Металлоискатель на принципе биения»

Локальный HTML/CSS/JS-сайт для демонстрации интерактивного электронного технического руководства учебного проекта по дисциплине «Автоматизация проектных работ».

## Запуск

Рекомендуемый вариант:

```bash
python -m http.server 8000
```

Затем открыть:

```text
http://localhost:8000
```

Если Python-сервер не запускается и установлен Node.js, можно использовать встроенный сервер без npm-зависимостей:

```bash
node server.mjs 8000
```

И открыть:

```text
http://127.0.0.1:8000
```

Прямое открытие `index.html` может не загрузить `assets/model.glb` из-за ограничений браузера на локальные ES-модули и файлы моделей.
Также подойдёт любой другой статический HTTP-сервер, запущенный из этой папки.
Для текущей версии нужен доступ к CDN `unpkg.com`, откуда загружается Three.js.

## Структура

```text
index.html        интерфейс ИЭТР
style.css         визуальный стиль
script.js         3D-сцена, маркеры, переключение разделов и шагов
data.js           структурированные данные ИЭТР
server.mjs        локальный статический сервер без зависимостей
assets/metal_detector_named.glb           основная именованная 3D-модель
assets/metal_detector_named_exploded.glb  запасной экспорт разнесенной сборки
assets/model.glb                          прежняя модель, оставлена как резерв
```

## Требования к 3D-модели для следующего этапа

Текущий сайт использует `assets/metal_detector_named.glb`. В модели найдены именованные узлы `pcb`, `cover-2`, `case-1`, `eBom-prt36-1`, `XP1`, `V1`, `RV1`, `LS1`, `R22`.
Для элементов платы работает выбор кликом по 3D-модели: резисторы `R1-R22`, конденсаторы `C1-C14`, диоды `D1-D3`, транзисторы `VT1-VT6`, разъемы `XP1`, `V1`, `LS1` и потенциометр `RV1`.

Прежний `assets/model.glb` пригоден только для общего просмотра: онлайн-конвертер переименовал узлы модели в технические `Node0...Node14`, поэтому сайт не мог надежно понять, где отдельная крышка, плата, разъемы и корпус.

Для полноценной анимации сборки лучше экспортировать из SolidWorks или Компас-3D новый `GLB/GLTF`:

- сохранять структуру сборки, не объединять все детали в один меш;
- дать деталям понятные имена: `case`, `cover`, `pcb`, `battery`, `coilCable`, `gland`, `membrane`, `ls1`, `rv1`, `xp1`, `v1`, `fasteners`;
- оставить единицы в миллиметрах;
- не включать лишние оси, плоскости, эскизы и служебную геометрию;
- GLB предпочтительнее STL, потому что STL не хранит имена деталей и материалы.
